# Nexus Core / Ядро

A personal hardware core that outlives devices.  
Персональное аппаратное ядро, которое переживает устройства.

## Principle / Принцип

- **Core** — square, metal, 20+ years.  
  **Ядро** — квадратное, металлическое, 20+ лет.

- **Shells** — interchangeable. Keyboard, battery, projector, slider.  
  **Оболочки** — сменные. Клавиатура, батарея, проектор, слайдер.

- **Handshake** — no shell works without cryptographic authentication by the core.  
  **Рукопожатие** — ни одна оболочка не работает без криптографической авторизации ядром.

- **Identity** — stored in the core. Shells are just tools.  
  **Идентичность** — хранится в ядре. Оболочки — просто инструменты.

## Why / Зачем

Most devices die because of planned obsolescence, broken screens, dead batteries.  
The core stays. Swap the shell — keep your data, your keys, your self.

Большинство устройств умирают из-за запланированного устаревания, разбитых экранов, севших батарей.  
Ядро остаётся. Меняй оболочку — сохраняй данные, ключи, себя.

Концепт. Открыт для сотрудничества.
